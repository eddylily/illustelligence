# Illustelligence

※ 해당 프로젝트는 한양대학교 ERICA에서 주최하는 2025학년도 소프트웨어융합대학 캡스톤 FAIR에서 발표 예정입니다.

## 개요
 본 프로젝트는 원하는 그림의 러프를 보다 구체적으로 그려낼 수 있는 툴로서 기획・개발되었습니다. 기존의 Stable Diffusion WebUI의 경우, 입력받은 프롬프트만으로 이미지를 그려내기 때문에 // 직군 특성상 macOS 및 iPadOS 사용 비율이 높은 만큼 호환성을 고려하여 웹앱으로 개발하였습니다. 해당 앱을 통해 일러스트레이터에게 작업을 의뢰하려는 클라이언트가 보다 쉽게 자신의 구상을 이미지화할 수 있고, 일러스트레이터 본인이 직접 아이디어를 구상할 때에도 사용될 수 있을 것입니다.
