# Draw your prompts ー Illustelligence

※ 해당 프로젝트는 **한양대학교 ERICA**에서 주최하는 **2025학년도 소프트웨어융합대학 캡스톤 FAIR**에서 발표 예정입니다.

## 개요
- 주제: 다중 프롬프트 및 드로잉 인터페이스를 접목한 이미지 생성형 인공지능
- 개발: 박유상 (한양대학교 ERICA 인공지능학과 학부 4학년)
- Contact: edxnya@gmail.com

## 소개
 본 프로젝트는 사용자가 원하는 이미지를 보다 구체적으로 생성해낼 수 있는 툴로서 기획・개발되었다. 기존의 Stable Diffusion 모델의 경우 입력받은 프롬프트만으로 이미지를 그려내기 때문에, 도구에 대한 이해가 부족한 일반 사용자가 쓰기에 다소 어려운 면이 있었다. 본 프로젝트에서는 이러한 사용성을 개선하고자 사용자가 프롬프트로 입력한 사물을 캔버스 상의 원하는 영역에 직관적으로 배치할 수 있도록 GUI를 도입하였다. 최대 다섯 개의 프롬프트를 작성할 수 있으며, 각각의 프롬프트 별로 따로 위치와 크기를 지정할 수 있다.
 
 프로젝트 진행에 앞서 진행한 현업 일러스트레이터 분들과의 인터뷰에서, 일러스트의 초기 구상 단계에서 인공지능을 활용할 수 있으면 좋겠다는 의견을 받았다. 해당 앱을 통해 일러스트레이터에게 작업을 의뢰하려는 클라이언트가 보다 쉽게 자신의 구상을 이미지화할 수 있고, 일러스트레이터 본인이 직접 아이디어를 구상할 때에도 사용될 수 있을 것이다. 분야 특성상 macOS 및 iPadOS 사용 비율이 높은 만큼 호환성을 고려하여 웹앱으로 개발하였다.
